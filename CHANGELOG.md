# Changelog

## 0.4.0

### Changed

- Adapt explanation depth and route to the reader's task rather than requiring a full walkthrough for every answer.
- Prioritize explicit audience, language, format, length, and source constraints over skill defaults within host instruction boundaries.
- Keep diagnostic references conditional and limit multi-source handling to material differences in state, provenance, and coverage.
- Complete routine explanatory tasks without unnecessary confirmation and stop checking when relevant issues are resolved.

### Added

- Guidance for mixed requests, unavailable sources, embedded source instructions, and supported corrections to source errors.
- Regression cases for concise and structured output, expert readers, requested depth, source isolation, and implicit or explicit skill selection.
- Synthetic source fixtures and an evaluation protocol with independent checks for fidelity, comprehension, reader fit, and economy.

### Fixed

- Unsupported review-clock resumption conditions in the teaching example.
- Evaluation tasks that referenced source material without supplying it.
- Rule mappings for historical evidence, argument structure, and repository-scope constraints.
- Documentation of installation contents, bilingual entry points, and the script-free project layout.
